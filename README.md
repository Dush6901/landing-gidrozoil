# Гидрозоил 

🌐 **Демо:** [Открыть лендинг](https://dush6901.github.io/landing-gidrozoil/)

**Гидрозоил** — адаптивный одностраничный лендинг компании, разработанный с использованием HTML и CSS.

## ✨ Возможности

- **Одностраничный сайт** — представление информации о компании на одной странице.
- **Навигация по секциям** — быстрый переход к основным разделам лендинга.
- **Адаптивный дизайн** — корректное отображение на мобильных устройствах, планшетах и компьютерах.
- **Семантическая разметка** — использование HTML5-тегов для структурирования содержимого.
- **Стилизация интерфейса** — оформление элементов страницы с помощью CSS.

## 🛠️ Технологии

- **HTML5** — структура и семантическая разметка страницы.
- **CSS3** — стилизация элементов и адаптивная вёрстка.
- **Git и GitHub** — контроль версий и хранение исходного кода.
- **GitHub Pages** — публикация сайта.

## 🚀 Запуск проекта

Для просмотра сайта локально:

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Dush6901/landing-gidrozoil.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd landing-gidrozoil
   ```

3. Откройте файл `index.html` в браузере.

Также можно воспользоваться расширением Live Server в Visual Studio Code для локального запуска сайта.

## 🎯 Цель проекта

Проект создан для практики frontend-разработки, закрепления навыков семантической HTML5-разметки, адаптивной вёрстки и организации структуры одностраничного сайта.
